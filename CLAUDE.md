# sg-content: read before acting

This repo makes and posts the founder's videos (Learning with SG and SG-MYTH-WORLD). The same founder runs arthvan-media,
ScoreMyBiz and Waypoint; sessions run on the Mac (VS Code), the phone and in the cloud, so the repo is the shared memory.

1. Start with `git pull --ff-only`. If it fails, or `git status` shows unsaved work, stop and tell the founder before changing anything.
2. Read `docs/decisions.md`: settled founder decisions for all four projects. Follow them; never ask again about a settled one.
3. Read `git log --oneline -15` to see what changed recently and why.
4. When the founder settles something new, add one line to `docs/decisions.md` (who, date) in the same commit. Commit messages say why.
5. Times told to the founder are in WAT (Lagos). Push only with the founder's yes.
